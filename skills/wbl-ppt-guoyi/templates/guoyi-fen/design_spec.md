# 品牌粉PPT模板 — Design Specification

## I. Template Overview

示例企业企业品牌演示文稿模板。设计取向：**极简、大留白、冷灰 + 一点粉、平面色块、左对齐**。

**规则分三级**，生成时按级别区别对待（与 `references/design-system.md` 第 0 节一致）：

| 级别 | 处理方式 |
|------|----------|
| 硬约束 | 必须遵守，无例外 |
| 设计原则 | 结合页面情况判断，允许合理偏离 |
| 参考区间 | 可偏离；偏离时在交付说明里讲一句理由 |

**页眉**：只有"左对齐 26px 深色标题 + 右上 LOGO"。不要顶部粉线、方块品牌标、全宽分隔线。
**容器**：用 `#F7F8FA` 平面色块分层级，不用描边。
**统一网格**：左右边距 80px（内容区 x=80 → x=1200，宽 1120px）；栏间距 24px；两栏各 548px，三栏 357/357/358px。

## II. Color Scheme

| 色值 | 角色 | 用途 |
|------|------|------|
| `#CF2154` | 主色 Primary | **只做强调**：序号、关键词、章节短线、对比强调 |
| `#FCE8EE` | 极浅粉 | 仅在双栏对比里给需突出的一栏做底 |
| `#FDEEF3` | 水印粉 | 章节页大号水印数字、封面几何圆 |
| `#212121` | 标题 Ink | 标题、关键文案 |
| `#4B5563` | 正文 Text | 正文、卡片内容、表格正文 |
| `#6B7280` | 注释 Text-3 | 注释、来源、页码、次要标注 |
| `#F7F8FA` | 色块底 Surface | 卡片/色块默认底色 |
| `#EEF0F3` | 次级底 Surface-2 | 表头底、次级色块、象限标题条 |
| `#E3E6EB` | 三级底 Surface-3 | 轨道、分隔带 |
| `#FFFFFF` | 页面底 | 页面背景 |

**粉色角色分工（最重要）**：主色是强调色，不是结构色。
拿掉页面所有粉色后结构仍应清晰；若变得不可读，说明粉色被当成了结构。

粉色**不要**出现在：页面标题字、容器描边、表格表头底、全宽顶线、正文。

## III. Typography

### III-a. 字阶（5 档）

| 档 | 用途 | 参考字号 | 字重 | 颜色 |
|----|------|----------|------|------|
| 1 | 封面主标题 | 40px | Bold | `#212121` |
| 2 | 内容页标题 / 章节页标题 | 26px / 40px | Bold | `#212121` |
| 3 | 小节标题、卡片标题 | 17–18px | Bold | `#212121` |
| 4 | 正文、表格正文、结论条 | 14px | Regular | `#4B5563` |
| 5 | 明细、注释、来源、页码 | 13px | Regular | `#6B7280` |
| 装饰 | 目录编号 40px；章节水印 160px | — | Bold | `#CF2154` / `#FDEEF3` |

字号全部挤在 16–24px 会让页面发扁。**相邻两档差距太小就没有层级**，宁可少用一档。

字体族：中文 **Microsoft YaHei**；数字 **Arial**；URL / 代码 **Consolas**。**不要写成中文名「微软雅黑」**（PPTX 导出会走形）。

### III-b. 硬约束

| 规则 | 标准 |
|------|------|
| 正文下限 | ≥13px；已知投屏场合 ≥15px |
| 字体族 | 微软雅黑 / Arial / Consolas，不混入其他字体 |
| 唯一彩色 | 全文档只有 `#CF2154` 一种彩色 |
| 禁止 Emoji | 全程不得出现 emoji |

### III-c. 内容密度（按原则判断，非硬指标）

不要按"最多几行"硬切。判断依据是**信息组**：

- 一个色块讲一件事，块内条目超过 5 条时考虑拆成两块或拆页
- 超出空间时优先：提炼关键词 → 合并同类条目 → 拆页；不要缩到 13px 以下
- 页尾允许留白 15–25%，不要为填满而拉大字号或缩紧行距

参考区间：结论条/明细块 3–4 行；表格行高 44–52px。

## IV. Signature Design Elements

**内容页（无固化模板，按本节规范现场写）**
- 页面标题：x=80，基线 y=96，26px，`#212121`，Bold
- LOGO：`<image href="../images/logo.png" x="1041" y="44" width="220" height="31"/>`（源在 `images/logo.png`）
- 内容带：y=168 → y=656（高 488）
- 页脚：左 `{{SOURCE}}` 12px `#6B7280`（可选）+ 右 `{{PAGE_NUM}}` 13px `#6B7280`；无横线

**章节页（03a）**（成品章节页**不放 LOGO**，实测确认）
- 水印数字：x=799，基线 y=550，230px，`#FDEEF3`，Bold，**每个章节页都要有**
- 章节标题：x=80，基线 y=264，40px，`#212121`，Bold
- 短粉线：x1=80 → x2=200，y=301，3px，`#CF2154`
- 要点：x=80，基线 y=391 起，行距 51，18px，`#4B5563`；按实际条数保留前 N 行、删掉多余行
- **不放 PART 标签、不放 LOGO**

**封面（01）**
- 左侧粉竖条：x=80, y=96, w=5, h=562，`#CF2154` opacity 0.18
- 几何纵深：两圆 cx=1060 cy=490 r=210（opacity .03）+ cx=940 cy=570 r=130（opacity .02）
- 左对齐（x=136）：标题 40px y=196 → 副标题 22px y=270（关键词可加 `<tspan fill="#CF2154">`）→ 320×3px 粉线 y=344 → 作者 17px `#4B5563` y=539 → 单位/日期 14px `#6B7280` y=581

**结尾（05）**：左对齐、极简。行动句 22px `#4B5563`（基线 y=254）→ 结语 64px `#212121` Bold（基线 y=426）→ 320×3px 粉线（y=472）。**不放联系信息、不放版权行、不放装饰圆**

**目录（02）**
- 标题"目录"：x=80，基线 y=112，28px，`#212121`，Bold
- 卡片：4 张单行，x=80 / 366 / 652 / 938，w=262，y=192，h=356，`#F7F8FA`
- 卡内文字左内边距 28：编号 40px `#CF2154` 基线 y=272 → 标题 18px `#212121` Bold 基线 y=332 → 子项 13px `#6B7280` 基线 y=388 / 414 / 440（`•` 前缀，最多 3 条）
- 章节数 ≠ 4 时按同一网格增减卡片或换行，**不要为凑 4 卡编内容**
