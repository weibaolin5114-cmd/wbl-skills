## 2.x

- v2.1.2（2026-10-26）：上架 SkillHub，标题定为「核心内容抓取」。`description` 开头补该名称并加入触发词（原名只有「提取笔记 / 文章转笔记」，市场里搜新标题命不中）。内部 `name` 仍为 `wbl-note-extract`——仓库映射、自动化任务、本地目录都按此名索引，改名断链。
- v2.1.1（2026-10-26）：补两条兜底判据 + 收窄误报。① `**「X」和「Y」**` 这类首尾标点配对、内含同类引号的写法，只外置单侧会留下 `「**X」和「Y**」`；② `\*\*` 出现奇数次时脚本原先静默跳过，预览仍留字面 `**`，改为报 WARN；③ 4 个以上连续星号（`****你好****`）是定界符翻倍，动了更乱，整行跳过并报 WARN。误报收窄：单/双星斜体、`C***de` 遮蔽字、`***` 分隔线、`src/**/*.py` 通配符都不算问题。首版用「星号为奇数」当判据时全库误报 88 处，改成「非代码段的转义星对数为奇数」后收敛到 1 处。
- v2.1.0（2026-10-26）：补 Markdown 格式规范化。起因：一篇落盘后预览里加粗显示成字面 `**`、无序列表显示 `• •`、有序列表显示 `1. 1.`。两处独立成因：加粗是抓取时 `**` 被写成 `\*\*`，且 `**` 外侧紧贴引号时 markdown-it 按 CommonMark flanking 规则不渲染；列表是原文 `li` 自带的 `•` / `1.` 被当正文抓进来，又叠加了自造标记。新增 3 条写作硬规则、2 项审核清单、落盘后自检，以及 `scripts/md_normalize.py`。
- v2.0.1（2026-10-13）：标签数量统一为 1~3 个（原为 3~5），与 `AGENTS.md`、自动化任务 02、线上提示词对齐。
- v2.0.0（2026-10-09）：去平台商标词，改为按页面类型分类。本技能曾因描述含第三方社区平台商标词在外部市场被自动下架（2026-10-08），核查为本体不调用该平台接口、不复制其素材，属关键词扫描误伤。输入改按「静态文章页 / 需渲染的动态页 / 图文卡帖页」三类划分。技术能力不变。微信公众号判据保留——微信是常用来源且判据最精细。
